# Central de Utilidades

Projeto Integrador desenvolvido para a disciplina **Programação Web I**, do curso Técnico em Informática para Internet do IF Sudeste MG. A página reúne ferramentas para ajudar em cálculos comuns do dia a dia.

## Acessar o projeto

**GitHub Pages:** https://gabrielgeoffroy.github.io/Projeto-Integrador-IF-Sudeste-MG-/

## Ferramentas

- **Calculadora de descontos:** informa a economia e o preço final de um produto.
- **Calculadora de parcelas:** divide o valor de uma compra em parcelas sem juros.
- **Simulador de investimentos:** estima o saldo final, o total investido e o rendimento, usando aportes ao fim de cada mês.
- **Divisor de despesas:** soma despesas identificadas e calcula quanto cada pessoa deve pagar.

As ferramentas podem ser usadas pelos formulários da página ou pelo modo **Prompt/Alert**.

## Tecnologias

- HTML5
- CSS3
- JavaScript

O projeto não utiliza frameworks ou bibliotecas externas.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências ou iniciar um servidor local.

## Arquivos

- `index.html` — estrutura e conteúdo da página.
- `style.css` — identidade visual e estilos responsivos.
- `script.js` — cálculos, validações e interações.
